# GoStudy — исправление финансов и мобильной шапки

Дата: 27 сентября 2026 года.

## Что исправлено

- Уроки со статусом «Без начисления» и «Возвращено» показывают фактически начисленные преподавателю `0 ₽`.
- Стоимость урока сохраняется в строке и подробной карточке как справочная информация.
- В подробной карточке выводится причина отсутствия начисления.
- На экранах до 520 px восстановлен безопасный верхний отступ кабинета: кнопка-гамбургер больше не перекрывает имя пользователя.

## Установка

1. Остановить фронтенд через `Ctrl+C`.
2. Распаковать архив в корень проекта `E:\Project\gostudy` с заменой файлов.
3. Запустить приложение обычным способом.

Миграция Prisma и повторная генерация клиента для этого исправления не нужны.

## Проверки

- `npm run lint`
- `npm run build`

Обе проверки пройдены перед упаковкой архива.
