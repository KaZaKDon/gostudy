# GoStudy — чтение родителем переписки ребёнка

Дата: 8 сентября 2026 года.

## Сделано

- в кабинете родителя добавлена вкладка «Чаты детей»;
- родитель видит переписки привязанных детей с преподавателями;
- история сообщений и вложения доступны для просмотра и скачивания;
- отправка от имени ребёнка запрещена на сервере;
- собственные чаты родителя с преподавателями вынесены во вкладку «Мои чаты с преподавателями»;
- ученик и преподаватель видят уведомление о подтверждённом родительском доступе;
- сохранено чтение архивной переписки без возможности отправки.

## Проверка

- 137 из 137 серверных тестов — успешно;
- TypeScript и production-сборка server — успешно;
- ESLint frontend — успешно;
- production-сборка React — успешно.

## Установка

Новая миграция базы данных не требуется. Заменить файлы из архива, пересобрать
и перезапустить Node API и frontend.
