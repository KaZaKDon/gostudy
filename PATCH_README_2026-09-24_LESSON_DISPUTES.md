# GoStudy — патч «Споры по урокам»

Архив распаковывается в корень проекта `E:\Project\gostudy` с заменой файлов.
Он рассчитан на актуальную установленную версию проекта после патча очистки
файлов класса.

## Что добавлено

- отдельный NestJS-модуль обращений участников;
- отдельный административный модуль модерации;
- обращения преподавателя, ученика и подтверждённого родителя;
- ответы сторон и приватные подтверждающие файлы;
- очередь споров в админке;
- статусы, решение модератора, журнал событий и административный аудит;
- уведомления и переход сразу к нужному спору;
- учёт вложений в общей квоте 300 МиБ;
- 7 новых модульных тестов.

Платёжные операции и автоматические перерасчёты этим патчем не выполняются.

## Установка

Остановить API, распаковать архив с заменой файлов, затем выполнять команды по
одной:

```powershell
npm run server:prisma:generate
npm --prefix server run prisma:migrate:deploy
npm --prefix server run prisma:status
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

После успешных проверок снова запустить API.

## Ручная проверка

1. Войти преподавателем или учеником.
2. Открыть `Споры → Открыть спор`.
3. Выбрать завершённый либо отменённый урок, заполнить описание и при желании
   приложить файл.
4. Войти второй стороной и добавить ответ.
5. В админке открыть `/admin/lesson-disputes`, взять спор в работу и сохранить
   решение с обоснованием.
6. Проверить уведомления сторон и итог в их кабинетах.

Подробное устройство и API описаны в `docs/LESSON_DISPUTES_V1.md`.
