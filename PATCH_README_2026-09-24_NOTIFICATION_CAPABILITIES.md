# GoStudy: честный статус возможностей уведомлений

Дата: 24 сентября 2026 года.

## Что изменено

- добавлен отдельный маршрут `GET /api/v1/notifications/capabilities`;
- сервер сообщает фактическое состояние внутренней ленты, email-доставки,
  автоматической очистки и доставки в реальном времени;
- настройка писем родителю сохраняется как подготовка к будущему запуску, но
  больше не отображается как работающая рассылка;
- неподключённая автоматическая очистка больше не обещает удаление через 30 и
  180 дней;
- интерфейс прямо сообщает, что уведомления сейчас удаляются вручную через
  колокольчик;
- общая карточка режима хранения вынесена в отдельный компонент;
- загрузка контракта возможностей вынесена в отдельный React-хук;
- прежний дублирующий компонент настроек использует единую реализацию;
- добавлены серверные регрессионные тесты и обновлена документация.

Миграция базы данных не требуется. Реальная отправка учебных писем этим патчем
не подключается.

## Установка

1. Остановите frontend и API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Выполните команды по одной:

```powershell
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

Ожидаемый итог backend-тестов: `65 passed`, `256 passed`.
