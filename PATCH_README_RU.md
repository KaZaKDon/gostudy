# GoStudy: фото профиля и видеовизитка на Node/PostgreSQL

Патч переносит загрузку, приватное хранение, проверку и публикацию фотографии
преподавателя и видеовизитки на новый сервер GoStudy.

## Что изменено

- Новые фото и видео сохраняются в закрытом хранилище Node-сервера.
- До решения администратора файл видят только преподаватель и модераторы.
- При загрузке замены прежний подтверждённый файл остаётся публичным.
- После подтверждения новый файл становится публичным, а прежний получает статус
  `REPLACED`.
- После отклонения прежний подтверждённый файл остаётся без изменений.
- Добавлен раздел админки `/admin/profile-media` с просмотром, подтверждением и
  отклонением файлов.
- Прямое изменение публичных URL из формы преподавателя заблокировано сервером.
- Фотография: JPG, PNG или WebP, не более 5 МБ, минимум 300 x 300 пикселей.
- Видеовизитка: MP4 или WebM, не более 100 МБ; публичная отдача поддерживает Range.

## Установка

1. Остановить API и фронтенд.
2. Сделать резервную копию базы и каталога приватных загрузок.
3. Распаковать архив в корень проекта `E:\Project\gostudy` с заменой файлов.
4. В PowerShell выполнить:

```powershell
cd E:\Project\gostudy\server
npm run prisma:migrate
npm run prisma:generate
npm run lint
npm run start:dev
```

Важно: используйте именно команды `npm run prisma:migrate` и
`npm run prisma:generate`. Не запускайте `npx prisma` отдельно — он может предложить
установить несовместимую предварительную версию Prisma.

5. В другом окне запустить фронтенд:

```powershell
cd E:\Project\gostudy
npm run dev
```

## Проверка

1. В кабинете преподавателя загрузить новое фото.
2. Убедиться, что рядом появился статус «На проверке», а прежнее публичное фото не
   исчезло.
3. Открыть `/admin/profile-media`, просмотреть файл и подтвердить его.
4. Обновить кабинет и публичную анкету: должно появиться новое фото.
5. Повторить проверку для видеовизитки.
6. Загрузить ещё одну замену и отклонить её: прежний подтверждённый файл должен
   остаться публичным.

## Старые файлы PHP

Текущие ссылки на старые фото и видео продолжают работать. Их перенос необязателен
для установки патча. Для отдельного переноса подготовлена команда:

```powershell
npm run profile-media:import-legacy -- --manifest путь\к\manifest.json --source-root путь\к\старым\файлам
```

Формат manifest и безопасная процедура описаны в
`docs/TEACHER_PROFILE_MEDIA_NODE.md`. Импорт копирует файлы и не удаляет оригиналы.
