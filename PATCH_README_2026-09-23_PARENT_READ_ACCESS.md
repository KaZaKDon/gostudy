# GoStudy: единый доступ родителя к данным детей

Дата: 23 сентября 2026 года.

## Что изменено

Расписание, дневник, домашние задания, семейная главная страница и уведомления
переведены на общий `ParentChildAccessService`.

Единое правило теперь одновременно проверяет:

- принадлежность карточки авторизованному родителю;
- подтверждение и отсутствие архивации карточки;
- активную подтверждённую связь с аккаунтом ученика;
- несовершеннолетний возраст ребёнка на текущую дату.

Общий сервис возвращает не только идентификатор ребёнка, но и безопасный
контекст для интерфейса: ФИО и часовой пояс. Для рассылки уведомлений добавлена
пакетная проверка через уже открытую Prisma-транзакцию.

Повторяющиеся запросы и копии правил удалены из пяти прикладных модулей.
Миграция базы данных не требуется.

## Установка

1. Остановите API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Из корня проекта выполните команды по одной:

```powershell
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

Ожидаемый результат тестов: 60 файлов, 241 тест.
