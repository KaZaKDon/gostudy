# GoStudy Teacher Badges

Готовый комплект SVG-значков преподавателя для размещения в проекте.

## Состав

- `svg/` — отдельные прозрачные SVG-файлы размером 120×120;
- `preview/badges-preview.svg` — общий лист предпросмотра;
- `badges.json` — машинно-читаемый список кодов, названий и путей;
- `badge-rules.md` — правила присвоения и отображения.

## Подключение

Папку можно целиком разместить, например, в:

`frontend/src/assets/badges/gostudy-teacher-badges/`

В приложении рекомендуется хранить у преподавателя коды полученных статусов, а название, подсказку и путь к SVG получать из `badges.json`.

## Важные правила

- Для серий оценок, стажа и количества уроков показывается только высшая актуальная ступень.
- `T09` зарезервирован и не означает платное продвижение.
- Публичная карточка не показывает ещё не полученные статусы.
