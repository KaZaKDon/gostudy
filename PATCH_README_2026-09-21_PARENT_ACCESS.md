# GoStudy — единый родительский доступ к сообщениям и отзывам

Патч устанавливается поверх `gostudy-main (10)` с сохранением структуры папок.

## Что изменено

- добавлен отдельный `ParentChildAccessModule`;
- сообщения и отзывы используют единое правило подтверждённого
  несовершеннолетнего ребёнка;
- после 18 лет родитель больше не получает детский чат и не оставляет отзыв от
  имени ребёнка;
- собственная переписка родителя остаётся в истории без возможности отправки;
- просмотр детского чата родителем не помечает сообщения прочитанными за
  ученика и не изменяет его счётчик;
- исправлено скачивание вложений родителем из доступного детского чата;
- добавлены регрессионные тесты и обновлена документация.

Миграция базы данных для этого патча не требуется.

## Установка

1. Остановить API сочетанием `Ctrl+C`.
2. Распаковать архив в `E:\Project\gostudy` с заменой файлов.
3. В корне проекта выполнить:

```powershell
npm run server:lint
npm run server:test
npm --prefix server run test:modules
npm run server:dev
```

Frontend перезапускать отдельно не требуется, если он уже работает в режиме
Vite. Изменений Prisma-схемы и миграций в архиве нет.
