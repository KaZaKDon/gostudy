# GoStudy: единый доступ родителя к действиям ребёнка

Дата: 23 сентября 2026 года.

## Что исправлено

Заявки преподавателю и заявки по программе «Доступное образование» теперь
используют общий `ParentChildAccessService`, как сообщения и отзывы.

Родитель больше не может:

- отправить преподавателю заявку за ребёнка после его совершеннолетия,
  архивации карточки или отзыва подтверждённой связи;
- просматривать состояние связи с преподавателем от имени недоступного ребёнка;
- создать или подтвердить заявку «Доступного образования» после прекращения
  родительского доступа.

Проверка заявки преподавателю выполняется внутри существующей Prisma-транзакции.
Миграция базы данных не требуется.

## Установка

1. Остановите API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Из корня проекта выполните:

```powershell
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```
