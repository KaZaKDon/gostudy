# Патч GoStudy: статистика и выплаты преподавателя V1

## Установка

Распаковать архив в корень `E:\Project\gostudy` с заменой файлов.

Выполнить по порядку:

```powershell
npm run server:prisma:generate
npm --prefix server run prisma:migrate:deploy
npm --prefix server run prisma:status
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

После проверок перезапустить API и frontend.

## Результат

- финансовый снимок создаётся вместе с уроком;
- после завершения начинается 24-часовой срок оплаты;
- согласованная отмена закрывает начисление;
- активный спор выделяется в финансовой истории;
- раздел преподавателя «Финансы» использует реальные данные;
- демонстрационные суммы преподавателя больше не выводятся;
- админская сводка считает оплаченные уроки и ожидающие выплаты.

Подключение банка и реальные денежные операции в этот патч не входят.
