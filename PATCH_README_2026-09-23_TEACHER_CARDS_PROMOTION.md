# GoStudy: фотографии и блок продвижения преподавателей

Дата: 23 сентября 2026 года.

## Что изменено

- фотография в строке рейтинга увеличена до 108 пикселей и занимает почти
  всю высоту карточки с вертикальными отступами по 3 пикселя;
- фотография в подробной анкете увеличена до 200 пикселей;
- добавлены отдельные адаптивные размеры для планшета и телефона;
- строка рейтинга получила заметные состояния наведения и клавиатурного фокуса;
- подготовлен отдельный модульный блок `ПРОДВИЖЕНИЕ`;
- блок принимает максимум три карточки;
- вся карточка продвижения кликабельна, отдельной кнопки «Подробнее» нет;
- карточка содержит фотографию, имя, предмет, рейтинг и количество отзывов;
- API-контракт дополнен массивом `promoted_teachers`.

Платёжная активация продвижения пока не подключена. До появления активных
размещений сервер возвращает пустой массив, поэтому пустой блок не отображается
и не занимает место. Обычный рейтинг остаётся независимым от продвижения.

Миграция базы данных не требуется.

## Установка

1. Остановите frontend и API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Из корня проекта выполните команды по одной:

```powershell
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```
