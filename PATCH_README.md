# GoStudy: завершение поиска преподавателей

Патч устанавливается поверх ранее установленных патчей GoStudy, включая страницу тарифов и дополнение условий продажи материалов.

## Установка

1. Остановите Vite и Node-сервер.
2. Скопируйте содержимое архива в корень проекта GoStudy с заменой файлов.
3. Новую миграцию выполнять не нужно.
4. Запустите сервер командой `npm run server:dev` из корня проекта.
5. Запустите фронтенд командой `npm run dev` из корня проекта.

## Что изменено

- добавлена серверная и визуальная пагинация списка по 12 преподавателей;
- обычную заявку теперь может отправить родитель за выбранного подтверждённого ребёнка;
- сервер проверяет активную связь родителя с ребёнком и не принимает чужой `student_id`;
- при смене ребёнка отдельно загружаются его активные занятия и ожидающие заявки;
- место в рейтинге присваивается только после трёх опубликованных отзывов;
- преподаватели без трёх отзывов остаются в поиске с отметкой «Новый»;
- в карточке поиска показаны город, опыт и минимальная стоимость;
- в публичной анкете выведены первое занятие, результат для ученика, возрастные группы, направления подготовки, цены, ознакомительное занятие, комментарий к стоимости, расписание и видеовизитка;
- добавлены серверные тесты на 18 преподавателях и на заявку родителя за ребёнка.

## Что не входит в этот патч

Дипломы и сертификаты пока загружаются через старый PHP-модуль и не представлены в Prisma-модели Node-сервера. Их перенос требует отдельного этапа с закрытым файловым хранилищем и модерацией; этот патч не меняет приватные документы.

## Проверки

- TypeScript сервера: успешно;
- ESLint фронтенда: успешно;
- production-сборка Vite: успешно;
- полный набор серверных тестов: успешно;
- миграции и схема базы не изменялись.

Примечание: команда `nest build` в рабочей копии Codex не запускалась из-за старой повреждённой ссылки в локальном `node_modules/fast-uri`; проверка TypeScript и все серверные тесты прошли. После обычного `npm install` в проекте эта локальная проблема зависимостей не относится к исходному коду патча.
