# GoStudy: публичный доступ к медиа преподавателя

Патч устанавливается после
`gostudy_patch_2026-09-21_parent-access-modular.zip`.

## Что исправлено

- публично выдаются только подтверждённые медиа активного аккаунта с ролью
  преподавателя и подтверждённой анкетой;
- файлы заблокированного, архивного или удалённого аккаунта больше не
  выдаются сервером по прямой ссылке;
- новые публичные ответы не кешируются, поэтому статус владельца проверяется
  при каждом сетевом запросе;
- правила активного и опубликованного преподавателя вынесены в общую политику
  и используются поиском, подробной анкетой, заявкой ученика и медиа;
- `is_visible` по-прежнему управляет каталогом преподавателей: скрытие из
  поиска не ломает фотографию у уже связанных учеников.

Ответ, полученный до установки патча со старым `max-age=86400`, может
оставаться в кеше браузера до окончания прежнего срока — максимум 24 часа с
момента его получения.

## Установка

1. Остановить API через `Ctrl+C`.
2. Распаковать архив в корень проекта `E:\Project\gostudy` с заменой файлов.
3. Выполнить:

```powershell
npm run server:lint
npm run server:test
npm --prefix server run test:modules
npm run server:dev
```

Миграция базы данных не требуется.
