# GoStudy: модульный каталог преподавателей

Дата: 23 сентября 2026 года.

## Что изменено

- поиск, рейтинг, пагинация и подробная публичная анкета вынесены из общего
  `TeachersService` в отдельный `TeacherDirectoryService`;
- `TeachersService` оставлен только для отправки заявок преподавателям;
- общая проверка роли ученика или родителя и доступа к выбранному ребёнку
  вынесена в `TeacherApplicantAccessService`;
- формирование публичной карточки вынесено в чистый преобразователь
  `teacher-public-profile.mapper.ts`;
- обычные и будущие продвигаемые карточки используют один контракт данных;
- маршруты API и структура ответов сохранены без изменений;
- на мобильных экранах надпись `Новый` больше не заходит под фотографию;
- добавлены отдельные модульные тесты каталога, доступа и преобразователя.

Миграция базы данных не требуется.

## Установка

1. Остановите frontend и API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Выполните команды по одной:

```powershell
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```
