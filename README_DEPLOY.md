# GoStudy — подготовка к размещению на VPS

**Статус:** проект пока разрабатывается локально. Эта инструкция фиксирует
будущую схему размещения и будет дополнена перед первым производственным
запуском.

## Что будет размещаться

- собранный React frontend из `dist`;
- NestJS API из `server/dist`;
- PostgreSQL;
- общие юридические документы из `shared/legal`;
- отдельные публичное и закрытое файловые хранилища;
- Nginx как reverse proxy;
- systemd-сервис для API.

PHP-файлы из `docs/api/**/*.php.md` и `docs/admin/**/*.php.md` на VPS не
размещаются. Они являются архивным справочником для переноса функций.

## Планируемая схема Nginx

```text
https://gostudyonline.ru/          → React dist
https://gostudyonline.ru/api/v1/   → NestJS на 127.0.0.1:3001
https://gostudyonline.ru/uploads/  → разрешённые публичные файлы
```

Закрытые документы преподавателей не должны находиться в публичной директории.
API выдаёт их только после проверки роли и полномочий.

## Что потребуется перед переносом

1. Российский VPS с Ubuntu, Nginx и PostgreSQL.
2. Node.js актуальной LTS-ветки.
3. Производственный `server/.env`.
4. Реквизиты зарегистрированного ИП.
5. SMTP-доступ для `noreply@gostudyonline.ru`.
6. Настройки резервного копирования PostgreSQL и файлов.
7. После подключения оплат — параметры ЮKassa только через переменные среды.

## Обязательные проверки перед запуском

- все миграции Prisma применены;
- frontend и API собраны без ошибок;
- регистрация сохраняет три решения пользователя и версии документов;
- токены подтверждения email хранятся только в виде SHA-256;
- CORS разрешает только реальные адреса GoStudy;
- секреты отсутствуют в репозитории и frontend-сборке;
- закрытые файлы недоступны по прямому URL;
- Nginx ограничивает размер запросов и частоту обращений;
- PostgreSQL и пользовательские файлы резервируются вне основного сервера;
- юридические документы заполнены реквизитами ИП и проверены юристом.

Точные команды systemd, Nginx, резервного копирования и первого развёртывания
добавляются после получения доступа к VPS.
