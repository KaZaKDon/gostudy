# GoStudy: единая квота хранилища

Дата: 24 сентября 2026 года.

## Что изменено

- добавлен отдельный `StorageQuotaModule`;
- общий лимит действует для всех приватных пользовательских файлов;
- параллельные загрузки резервируют место атомарно;
- ошибки загрузки освобождают резерв и удаляют записанный файл;
- штатное удаление файла уменьшает счётчик в транзакции с удалением записи;
- миграция безопасно учитывает уже существующие файлы;
- добавлен `GET /api/v1/storage/usage`;
- во всех кабинетах появилась вкладка `Хранилище` с занятым и свободным местом;
- добавлены регрессионные тесты и документация.

Лимит по умолчанию — 300 МиБ на аккаунт. Его можно изменить в `server/.env`:

```dotenv
UPLOAD_USER_QUOTA_BYTES=314572800
```

Платные тарифы, карты и приём платежей этим патчем не подключаются.

## Установка

1. Остановите frontend и API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Выполняйте команды по одной:

```powershell
npm run server:prisma:generate
npm --prefix server run prisma:migrate:deploy
npm --prefix server run prisma:status
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

Ожидаемый итог backend-тестов: `66 passed`, `260 passed`.
