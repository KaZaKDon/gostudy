# GoStudy — завершённый функционал онлайн-класса

Дата: 12 сентября 2026 года.

## Итог этапа

Онлайн-класс функционально собран в модульном виде:

- защищённый вход ученика и преподавателя в конкретный урок;
- запуск, завершение, таймер и присутствие;
- чат занятия;
- закрытые материалы, предпросмотр и общий показ страниц;
- домашние задания и заметка преподавателя;
- realtime-события с резервной четырёхсекундной синхронизацией;
- WebRTC-камера и микрофон с отдельным управлением;
- демонстрация экрана преподавателем;
- совместная доска ученика и преподавателя;
- сохранение доски после обновления страницы;
- карандаш, четыре цвета, три толщины и ластик;
- очистка всей доски только преподавателем;
- фиксированные размеры блоков и внутренняя прокрутка;
- адаптивная компоновка для компьютера, планшета и телефона.

Каждый крупный инструмент изолирован: realtime, медиа, показ экрана и доска не
содержат бизнес-логику друг друга. Доска имеет собственные controller, service,
DTO, Prisma-модель, React-хук и компонент.

## Проверки

- Prisma-схема: валидна;
- 158 из 158 серверных тестов: успешно;
- TypeScript сервера: успешно;
- production-сборка NestJS: успешно;
- полный ESLint frontend: успешно;
- production-сборка React: успешно.

## Установка

Архив накопительный и заменяет три предыдущих пакета класса. Сначала наложить
его на проект, затем из корня проекта выполнить:

```powershell
npm run server:prisma:migrate
npm run server:prisma:generate
npm run server:build
npm run server:dev
```

Во втором терминале:

```powershell
npm run dev
```

Миграция создаёт только таблицу штрихов доски. Существующие уроки, сообщения,
материалы и результаты не изменяются.

## Следующий шаг

После установки проводится полный ручной тест онлайн-класса двумя аккаунтами.
Ошибки фиксируются списком и исправляются после прохождения всего сценария.

Для production-видеосвязи позже потребуется TURN-сервер и HTTPS. Локальная
проверка на `localhost` возможна без TURN.
