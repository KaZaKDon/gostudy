# Архивные PHP-файлы

Эта папка сохранена только как справочник различий между прежней хостинговой
версией PHP API и документацией.

Файлы из `HOST_API` не являются действующим backend, не копируются на новый VPS
и не изменяются при разработке NestJS. Нужные проверки и бизнес-правила
переносятся в соответствующие модули `server/src/modules`.
