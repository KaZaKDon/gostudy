# GoStudy: согласование имён индексов Prisma

Патч добавляет одну миграцию без изменения данных. Она согласует имена двух
индексов, которые PostgreSQL сократил из-за ограничения в 63 байта.

## Установка

1. Остановите API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. В корне проекта выполните:

```powershell
npm --prefix server run prisma:migrate:deploy
npm --prefix server run prisma:status
npm run server:lint
npm run server:test
npm run server:test:modules
```

4. Запустите приложение обычной командой проекта.

## Что изменено

- добавлена миграция `20260922190000_align_long_index_names`;
- добавлено описание причины и поведения миграции;
- обновлён индекс действующей документации.

Миграция безопасно пропускает индекс, если он уже имеет ожидаемое Prisma имя.
Старые миграции и их контрольные суммы не изменяются.
