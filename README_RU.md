## Установка
Распаковать в отдельную папку, НЕ поверх проекта.
Запустить Node-установщик из этой папки, указав путь к существующему проекту:

    node deploy/install-classroom-video-patch.mjs E:\Project\gostudy

На сервере (если нужна запись через sudo):

    sudo node deploy/install-classroom-video-patch.mjs /srv/gostudy/app

Установщик сначала проверяет SHA-256 обоих исходных файлов. При несовпадении останавливается до записи.
Копии прежних файлов сохраняются в ../backups/classroom-video-<дата>-<идентификатор>/ относительно проекта.
Повторная установка ничего не меняет. Конфигурация, зависимости, БД и Robokassa не затрагиваются.

Из корня проекта выполнить npm run lint, затем npm run build.
На сервере после успешной сборки опубликовать весь dist:

    sudo rsync -a --chown=ubuntu:www-data --chmod=D2750,F640 /srv/gostudy/app/dist/ /var/www/gostudy/

Не добавлять --delete: старые файлы ассетов нужны уже открытым вкладкам.
После публикации обновить страницу класса.

## Проверить в классе
На компьютере и телефоне: входящее видео в основном блоке, превью в углу.
Закрыть превью: собеседник по-прежнему слышит и видит вас. Вернуть превью кнопкой.
Проверить отключение камеры/микрофона, выход и повторное подключение, переход на доску и показ экрана.
Проверить с камерой 16:9 и вертикальным видео: изображение не обрезается и не растягивается.
