# GoStudy: расширенные фильтры каталога преподавателей

Дата: 23 сентября 2026 года.

## Что изменено

- добавлены фильтры по направлению подготовки, возрасту ученика, городу,
  минимальному стажу, максимальной цене занятия и минимальному рейтингу;
- существующие предмет, текстовый поиск и программа «Доступное образование»
  работают совместно с новыми условиями;
- параметры запроса и правила фильтрации вынесены в отдельные модули;
- справочники предметов, направлений, возрастов и городов приходят из API;
- при смене предмета несовместимое направление автоматически очищается;
- добавлена единая кнопка сброса поиска и всех фильтров;
- панель фильтров адаптирована для планшетов и мобильных экранов;
- фильтрация не пересчитывает и не улучшает место преподавателя в рейтинге;
- платное продвижение и оплата этим патчем не подключаются.

Миграция базы данных не требуется.

## Установка

1. Остановите frontend и API сочетанием `Ctrl+C`.
2. Распакуйте архив в `E:\Project\gostudy` с заменой файлов.
3. Выполните команды по одной:

```powershell
npm run lint
npm run build
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

Ожидаемый итог backend-тестов: `64 passed`, `253 passed`.
