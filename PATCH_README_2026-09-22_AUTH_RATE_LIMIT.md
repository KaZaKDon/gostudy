# GoStudy: ограничение запросов к авторизации

Патч устанавливается после двух патчей от 21 сентября 2026 года:

1. `gostudy_patch_2026-09-21_parent-access-modular.zip`;
2. `gostudy_patch_2026-09-21_teacher-media-access-modular.zip`.

## Что исправлено

- добавлен отдельный `AuthRateLimitModule`;
- ограничены вход пользователя и администратора, регистрация, подтверждение
  почты, повторная отправка письма и восстановление пароля;
- при превышении возвращается HTTP 429 с `Retry-After`;
- email, IP и токены не хранятся в корзинах открытым текстом;
- исключено прямое доверие пользовательскому `X-Forwarded-For`;
- число доверенных reverse proxy настраивается через `TRUST_PROXY_HOPS`;
- хранилище ограничителя отделено интерфейсом для будущего перехода на Redis.

Миграция базы данных не требуется. Текущая реализация рассчитана на один
процесс API; для нескольких процессов потребуется общее хранилище счётчиков.

## Установка

1. Остановить API через `Ctrl+C`.
2. Распаковать архив в `E:\Project\gostudy` с заменой файлов.
3. Проверить `server/.env`:

```text
AUTH_RATE_LIMIT_ENABLED=true
AUTH_RATE_LIMIT_MAX_BUCKETS=50000
TRUST_PROXY_HOPS=0
```

Для локального запуска оставить `TRUST_PROXY_HOPS=0`. Значение `1` потребуется
на VPS только при работе ровно через один доверенный Nginx.

4. Выполнить:

```powershell
npm run server:lint
npm run server:test
npm --prefix server run test:modules
npm run server:dev
```
