# GoStudy — преподаватели в админке на Node/NestJS

Дата: 3 сентября 2026 года.

## Назначение

Модуль даёт администратору и модератору полный просмотр анкеты преподавателя,
фильтрацию, подтверждение, возврат на доработку и управление публикацией в
поиске. Старые PHP-маршруты `/api/admin/teachers/*.php` frontend больше не
использует.

## Маршруты

Все маршруты требуют действующий административный токен в `X-Auth-Token`.

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/v1/admin/teachers` | администратор, модератор | список, поиск, фильтры и пагинация |
| `GET` | `/api/v1/admin/teachers/:id` | администратор, модератор | полная карточка преподавателя |
| `PATCH` | `/api/v1/admin/teachers/:id/verification` | администратор, модератор | подтверждение или возврат анкеты |
| `PATCH` | `/api/v1/admin/teachers/:id/visibility` | администратор, модератор | публикация или скрытие подтверждённой анкеты |

Блокировка, архивирование и восстановление выполняются общим маршрутом
`PATCH /api/v1/admin/accounts/:id/status`. Он доступен только администратору.

## Проверка анкеты

Используются статусы:

* `pending` — ожидает проверки;
* `verified` — подтверждена;
* `rejected` — возвращена на доработку.

Подтвердить можно только полностью заполненную анкету активного аккаунта. При
подтверждении анкета публикуется в поиске. При возврате на доработку обязателен
комментарий, а анкета скрывается.

После решения преподавателю создаётся внутреннее уведомление. Изменение
статуса проверки и ручное управление видимостью записываются в
`admin_audit_logs`.

Если преподаватель редактирует подтверждённую анкету, она снова получает
статус `pending`, скрывается из поиска и требует повторной проверки.

## Карточка преподавателя

Карточка показывает:

* аккаунт и его статус;
* основные и подробные поля анкеты;
* цены и описание занятий;
* предметы, направления и возрастные группы;
* образование;
* активных и архивных учеников;
* количество уроков и выданных домашних заданий;
* средний рейтинг и количество опубликованных отзывов.

Отзывы, ответы преподавателя и рейтинг подключены к Node-модулю отзывов.
Домашние задания и их закрытые материалы также подключены. Файлы документов
анкеты будут перенесены отдельным модулем после настройки российского VPS.

## Изменения базы данных

Миграция `20260902160000_admin_teachers` добавляет в `teacher_profiles`:

* `verification_comment`;
* `verified_by`;
* `verified_at`;
* индексы проверки и внешний ключ на администратора/модератора.

После получения файлов выполнить из корня проекта:

```powershell
npm run server:prisma:generate
npm run server:prisma:migrate
npm run server:prisma:status
```

После миграции перезапустить Node API и frontend.
