# GoStudy — статистика и выплаты преподавателя V1

Дата: 27 сентября 2026 года.

## Назначение

Модуль заменяет демонстрационные суммы в кабинете преподавателя реальными
данными уроков. Он отделён от расписания и будущего эквайринга: расписание
сообщает только о создании, завершении или отмене урока, а финансовый модуль
хранит неизменяемый снимок расчёта.

## Финансовый снимок урока

При назначении урока в `lesson_settlements` сохраняются:

- согласованная стоимость урока из анкеты преподавателя;
- процент комиссии опубликованного тарифа;
- сумма комиссии;
- сумма преподавателю;
- версия тарифа.

Изменение цен анкеты или публикация нового тарифа не меняют расчёты уже
назначенных уроков.

## Жизненный цикл

1. Новый урок получает статус оплаты `NOT_DUE`.
2. После завершения урока включается `AWAITING_PAYMENT` и срок оплаты 24 часа.
3. После истечения срока интерфейс показывает вычисляемое состояние
   `overdue`, не переписывая исходный статус операции.
4. Согласованная отмена переводит запись в `WAIVED`.
5. Активный спор имеет приоритет отображения `disputed` и не считается
   доступной выплатой.
6. Статусы `PAID`, `READY`, `PAYOUT_PAID`, `PAY_LATER` и `REFUNDED`
   подготовлены для административного платёжного контура и эквайринга.

Решение спора пока не выполняет денежные операции автоматически. Это
сознательная граница V1: модератор фиксирует решение, а будущий платёжный
модуль применит его к расчёту отдельным журналируемым действием.

## API

`GET /api/v1/teacher/finance`

Доступ: только авторизованный преподаватель.

Параметры:

| Параметр | Значения |
| --- | --- |
| `period` | `current_month`, `previous_month`, `90_days`, `all` |
| `status` | пусто, `awaiting_payment`, `overdue`, `pay_later`, `paid`, `ready_for_payout`, `payout_paid`, `disputed`, `waived`, `refunded` |
| `page` | номер страницы от 1 |
| `limit` | от 1 до 100 |

Ответ содержит:

- общую стоимость проведённых уроков;
- начисление преподавателю;
- удержанную комиссию;
- ожидающие и просроченные оплаты;
- спорные суммы;
- готовые и завершённые выплаты;
- постраничную историю уроков;
- опубликованные условия тарифа.

## Миграция существующих уроков

Миграция `20260927211500_teacher_finance_v1` создаёт финансовые снимки для
всех существующих уроков. Для исторических записей используется текущая цена
соответствующей продолжительности из анкеты преподавателя и активный
опубликованный тариф. После миграции эти значения фиксируются.

## Граница V1

В эту версию не входят:

- приём банковской оплаты;
- ручная финансовая модерация в админке;
- формирование платёжного поручения;
- сохранение реквизитов преподавателя;
- автоматическое применение решения спора к деньгам;
- реальные переводы и возвраты.

Структура статусов и финансовые снимки подготовлены так, чтобы эти функции
добавлялись отдельными модулями без изменения расписания и истории уроков.
