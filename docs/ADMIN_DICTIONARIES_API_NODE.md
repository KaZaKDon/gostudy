# GoStudy — справочники админки на Node/NestJS

Дата актуализации: 2 сентября 2026 года.

## Назначение

Административные справочники полностью подключены к PostgreSQL через единый
модуль NestJS `admin-dictionaries`. Старые PHP-маршруты
`/api/admin/dictionaries/**/*.php` остаются только архивной спецификацией и
frontend их больше не вызывает.

Все запросы передают отдельный административный токен в `X-Auth-Token`.
Администратор и модератор могут просматривать справочники. Создание, изменение,
удаление и настройка связей доступны только администратору; интерфейс модератора
не показывает кнопки изменения, а сервер дополнительно проверяет роль.

## Маршруты CRUD

| Ресурс | Базовый маршрут |
| --- | --- |
| группы предметов | `/api/v1/admin/dictionaries/subject-groups` |
| предметы | `/api/v1/admin/dictionaries/subjects` |
| группы подготовки | `/api/v1/admin/dictionaries/preparation-groups` |
| направления подготовки | `/api/v1/admin/dictionaries/preparations` |
| возрастные группы | `/api/v1/admin/dictionaries/age-groups` |

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `<базовый маршрут>` | администратор, модератор | получить список |
| `POST` | `<базовый маршрут>` | администратор | создать запись |
| `PATCH` | `<базовый маршрут>/:id` | администратор | изменить запись или статус |
| `DELETE` | `<базовый маршрут>/:id` | администратор | удалить неиспользуемую запись |

Предметы и направления принимают необязательные query-параметры `group_id`,
`is_active=0|1` и `search`.

Тело группы или возрастной группы:

```json
{
  "name": "Школьные предметы",
  "slug": "school-subjects",
  "sort_order": 10,
  "is_active": true
}
```

Для предмета и направления дополнительно обязательно поле `group_id`.
Slug состоит из строчных латинских букв, цифр и одиночных дефисов.

## Связи предметов и направлений

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/v1/admin/dictionaries/subject-preparations` | администратор, модератор | данные всей страницы связей |
| `GET` | `/api/v1/admin/dictionaries/subject-preparations/:subjectId` | администратор, модератор | связи одного предмета |
| `PUT` | `/api/v1/admin/dictionaries/subject-preparations/:subjectId` | администратор | полностью заменить и упорядочить связи |

Тело `PUT`:

```json
{
  "preparations": [
    { "id": 3, "sort_order": 10 },
    { "id": 7, "sort_order": 20 }
  ]
}
```

Повторяющиеся ID и несуществующие направления отклоняются. Нельзя удалить
связь, которую преподаватель уже выбрал в своей анкете.

## Защита данных

- названия проверяются без учёта регистра, slug уникален;
- группу нельзя удалить, пока в ней есть дочерние записи;
- предмет нельзя удалить, если он используется преподавателем, заявкой,
  учебной связью, уроком или направлением подготовки;
- направление и возрастную группу нельзя удалить, пока их используют анкеты;
- каждая операция изменения записывается в `admin_audit_logs` вместе с
  администратором, IP, User-Agent, старым и новым значением;
- изменения справочника и запись аудита выполняются одной транзакцией.

## Установка

Новая миграция Prisma не требуется: таблицы справочников уже входят в текущую
схему PostgreSQL. После замены файлов перезапустить backend и frontend:

```powershell
npm run server:dev
npm run dev
```

Для локальной разработки использовать `server:dev`. Команда `server:start`
запускает ранее собранный `server/dist` и без новой сборки не увидит добавленные
маршруты.
