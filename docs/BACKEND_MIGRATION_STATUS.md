## Правило переноса

PHP-файл не преобразуется автоматически строка в строку. Из него извлекаются
контракт, проверки и бизнес-правила. Затем функция реализуется модульно в
NestJS, проверяется тестами, подключается к React и только после этого получает
статус ✅.

Frontend обращается только к готовым маршрутам NestJS. Архивные PHP-файлы не
используются приложением во время выполнения и остаются только источником
контрактов для ещё не перенесённых областей.
