## Правило переноса

PHP-файл не преобразуется автоматически строка в строку. Из него извлекаются
контракт, проверки и бизнес-правила. Затем функция реализуется модульно в
NestJS, проверяется тестами, подключается к React и только после этого получает
статус ✅.

Пока модуль отмечен `⬜`, frontend не выполняет фоновые запросы к его старому
PHP API с Node-токеном. Это предотвращает повторяющиеся `401`; подключение
включается через `API_FEATURES` только вместе с готовым NestJS-маршрутом.
