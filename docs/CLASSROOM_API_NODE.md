# GoStudy — онлайн-класс на Node/NestJS

Дата: 11 сентября 2026 года.

## Назначение

`/classroom/:lessonId` — рабочее место одного занятия. Урок загружается только
из PostgreSQL, а право доступа проверяет сервер. Передача роли или данных урока
через React Router не используется.

## Главное правило завершения

Начать и завершить урок может только его преподаватель. Завершить можно только
сессию в состоянии `ACTIVE`. В одной транзакции сервер:

1. переводит `lesson_sessions.status` в `ENDED`;
2. фиксирует `ended_at` и преподавателя, завершившего урок;
3. переводит `lessons.status` в `COMPLETED`;
4. останавливает общий показ материала;
5. создаёт ученику уведомление.

Именно статус `COMPLETED` разрешает ученику оставить отзыв. Простого наступления
времени окончания, входа в комнату или создания урока для отзыва недостаточно.

## Жизненный цикл

- `WAITING` — вход разрешён, преподаватель ещё не начал урок;
- `ACTIVE` — урок идёт;
- `ENDED` — урок завершён и доступен только для чтения.

Вход открывается за 15 минут до начала. Если урок не был запущен, возможность
начала закрывается через 30 минут после его планового окончания. Уже активный
урок остаётся доступным до ручного завершения преподавателем.

## Маршруты

Все маршруты требуют действующий `X-Auth-Token`. Доступ есть только ученику и
преподавателю, указанным в конкретном уроке.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/v1/classroom/show?lesson_id=ID` | полное начальное состояние класса |
| `GET` | `/api/v1/classroom/events?lesson_id=ID` | защищённый поток событий класса в реальном времени |
| `POST` | `/api/v1/classroom/sync` | присутствие, новые сообщения, материалы и общий показ |
| `POST` | `/api/v1/classroom/start` | начать урок преподавателем |
| `POST` | `/api/v1/classroom/finish` | завершить урок и открыть возможность отзыва |
| `POST` | `/api/v1/classroom/send-message` | отправить сообщение в чат урока |
| `POST` | `/api/v1/classroom/media-signal` | передать защищённый WebRTC-сигнал второму участнику |
| `POST` | `/api/v1/classroom/save-note` | сохранить личную заметку преподавателя |
| `POST` | `/api/v1/classroom/upload-file` | загрузить закрытые материалы преподавателем |
| `POST` | `/api/v1/classroom/delete-file` | удалить материал преподавателем |
| `GET` | `/api/v1/classroom/download-file?file_id=ID` | защищённое скачивание или предпросмотр |
| `POST` | `/api/v1/classroom/share-material` | включить показ материала и страницы |
| `POST` | `/api/v1/classroom/stop-material-sharing` | остановить общий показ |
| `GET` | `/api/v1/classroom/board?lesson_id=ID&after_id=ID` | получить новые штрихи доски |
| `POST` | `/api/v1/classroom/board/strokes` | добавить штрих участника |
| `POST` | `/api/v1/classroom/board/clear` | очистить доску преподавателем |

`events` использует Server-Sent Events и открывается обычным защищённым
HTTP-запросом с `X-Auth-Token`. Сервер сначала проверяет, что пользователь —
ученик или преподаватель конкретного урока. События разделены по `lesson_id`,
поэтому изменение одного класса не запускает обновление других классов.

Сервер отправляет событие после запуска или завершения урока, нового сообщения,
изменения файлов, общего материала или присутствия участника. Получив событие,
frontend сразу запрашивает актуальное состояние через `sync`. Благодаря этому
в поток не передаются сами сообщения и закрытые данные материалов.

`sync` принимает `lesson_id` и `after_message_id`. Запрос каждые четыре секунды
сохранён как резервный режим и как сигнал присутствия. Если поток временно
недоступен, класс продолжает работать и автоматически пытается подключиться
снова. В заголовке класса отображается текущее состояние подключения. Вместе с
состоянием класса frontend получает актуальные домашние задания, связанные с
уроком. Чат урока отделён от общей переписки пользователей.

Текущая шина событий хранится в памяти Node API и рассчитана на один экземпляр
приложения. Перед запуском нескольких экземпляров публикацию следует перенести
на общий Redis Pub/Sub или другой брокер; контракт frontend менять не потребуется.

## Компоновка и прокрутка

На компьютере страница класса занимает ровно высоту окна браузера и не
увеличивается вслед за содержимым. Независимая внутренняя прокрутка действует
для:

- истории сообщений;
- материалов, домашних заданий и личной заметки;
- центральной рабочей области;
- предпросмотра PDF, DOCX, изображений и текста.

Заголовки, вкладки и форма отправки сообщения остаются внутри своих блоков и
не уходят вслед за прокруткой содержимого. На узких экранах последовательные
панели доступны через прокручиваемую область класса, но каждая наполняемая
карточка сохраняет ограниченную высоту. Панель инструментов на телефоне
прокручивается горизонтально.

## Закрытые материалы

Преподаватель может за один запрос загрузить до пяти файлов: PDF, JPG/JPEG,
PNG, WebP, TXT, DOC/DOCX, XLS/XLSX и PPT/PPTX. Проверяются:

- роль и участие в уроке;
- доступное время и состояние класса;
- расширение и заявленный MIME;
- сигнатура содержимого;
- размер каждого запроса и общий объём материалов урока;
- принадлежность файла уроку при скачивании и удалении.

По умолчанию используются лимиты 10 МБ на файл, 30 МБ на запрос и 100 МБ на
урок. Файлы не имеют публичных URL и выдаются только через авторизованный API.
Русские и другие UTF-8-названия нормализуются общим файловым модулем при
загрузке, отображении и скачивании. Уже сохранённые искажённые названия также
восстанавливаются при выдаче без повторной загрузки файла.

Локальная настройка `server/.env`:

```dotenv
UPLOAD_PRIVATE_DIR=storage/private
UPLOAD_CLASSROOM_MAX_BYTES=10485760
UPLOAD_CLASSROOM_TOTAL_MAX_BYTES=31457280
UPLOAD_CLASSROOM_LESSON_MAX_BYTES=104857600
```

На VPS `UPLOAD_PRIVATE_DIR` должен быть абсолютным путём вне корня сайта.

## Камера и микрофон

Вкладка «Видео» доступна после запуска урока. Ученик и преподаватель включают
камеру и микрофон самостоятельно и могут в любой момент отключить звук, видео
или полностью выйти из соединения.

Медиа передаётся браузерами напрямую по WebRTC и не записывается сервером
GoStudy. Node API проверяет урок и участника, затем пересылает через защищённый
поток только `offer`, `answer` и ICE-кандидаты адресату этого урока.

Для камеры и микрофона production-сайт обязательно должен работать по HTTPS.
Для устойчивой связи между разными домашними и мобильными сетями потребуется
TURN-сервер. Его реквизиты предусмотрены в корневом `.env`:

```dotenv
VITE_WEBRTC_TURN_URL=turn:turn.gostudyonline.ru:3478
VITE_WEBRTC_TURN_USERNAME=
VITE_WEBRTC_TURN_CREDENTIAL=
```

Пустые значения не мешают локальной проверке. До развёртывания TURN соединение
через публичный STUN может работать не во всех сочетаниях сетей; это ограничение
сетевой инфраструктуры, а не прав пользователей класса.

## Демонстрация экрана

Показ экрана использует уже установленное WebRTC-соединение и не создаёт второй
медиаканал. Запустить трансляцию может только преподаватель во время активного
урока. Браузер преподавателя сам показывает системное окно выбора вкладки,
программы или всего экрана — GoStudy не получает список открытых окон.

Ученик видит трансляцию во вкладке «Показать экран». При остановке кнопкой
GoStudy или системной кнопкой браузера видеосоединение автоматически возвращает
камеру преподавателя. Звук микрофона продолжает работать отдельно; системный
звук компьютера на этом этапе не передаётся.

## Совместная доска

Доска работает как самостоятельный модуль класса. Ученик и преподаватель могут
рисовать во время активного урока, выбирать цвет и толщину линии, использовать
ластик. Полностью очистить доску может только преподаватель.

Каждый законченный штрих хранится отдельной записью PostgreSQL. Это исключает
перезапись рисунка при одновременной работе и позволяет загружать только новые
штрихи по `after_id`. На один урок действует лимит 2000 штрихов, на один штрих —
500 нормализованных точек. После обновления страницы доска восстанавливается.
Realtime-событие сообщает только о факте изменения, а сами координаты участник
получает через защищённый Board API.

## База данных

Миграция `20260902213000_classroom`:

- расширяет `lesson_sessions` временем присутствия и участниками запуска/окончания;
- создаёт `lesson_messages`;
- создаёт `lesson_files`;
- создаёт `lesson_workspace_state`;
- создаёт `lesson_results`, которую использует действующий модуль журнала.

Миграция `20260912223000_classroom_board` создаёт отдельную таблицу
`lesson_board_strokes` с внешними ключами на урок и автора штриха.

После получения файлов выполнить из корня проекта:

```powershell
npm run server:prisma:generate
npm run server:prisma:migrate
npm run server:prisma:status
npm run server:dev
```

Во втором терминале:

```powershell
npm run dev
```

## Проверка

1. Преподавателем назначить урок на ближайшее время.
2. Раньше чем за 15 минут убедиться, что вход закрыт.
3. В разрешённое время войти учеником и преподавателем.
4. Преподавателем начать урок.
5. Убедиться, что у обоих участников показано «Связь в реальном времени».
6. Отправить сообщение и проверить его появление во втором окне без ожидания
   четырёхсекундного интервала.
7. Сохранить заметку и загрузить материал.
8. Включить общий показ материала преподавателем и проверить его у ученика.
9. Завершить урок преподавателем.
10. Проверить статус `COMPLETED` в расписании и уведомление ученика.
11. Преподавателем нажать «Заполнить журнал» и опубликовать результат.
12. Учеником открыть «Дневник обучения» и проверить запись без личной заметки.
13. Учеником открыть «Мои преподаватели» — форма отзыва должна стать доступна.

## Границы модуля

Домашние задания остаются самостоятельным модулем и подключены к боковой панели
класса через его публичный сервис. Production-инфраструктура TURN и будущая
горизонтальная шина событий разворачиваются отдельно от прикладного кода класса.
# Текст на совместной доске

Текстовые блоки хранятся отдельно от штрихов в `lesson_board_texts`. Участники
активного урока могут создавать текст, перемещать и редактировать собственные
блоки. Преподаватель может управлять любым блоком и очищать всю доску.

- `POST /api/v1/classroom/board/texts` — создать блок;
- `PATCH /api/v1/classroom/board/texts/:id` — изменить текст или положение;
- `DELETE /api/v1/classroom/board/texts/:id?lesson_id=...` — удалить блок.

Изменения синхронизируются событием `board` и сохраняются после перезагрузки.
