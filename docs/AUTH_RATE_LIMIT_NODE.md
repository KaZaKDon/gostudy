# GoStudy — ограничение частоты запросов к авторизации

Дата: 22 сентября 2026 года.

## Назначение

Публичные маршруты авторизации защищены от автоматического перебора паролей,
массовой регистрации и злоупотребления почтовыми отправками. Ограничитель
вынесен в отдельный `AuthRateLimitModule` и не смешан с бизнес-логикой
`AuthService` и `PasswordRecoveryService`.

В памяти не сохраняются email, IP-адреса и токены в открытом виде. Для ключей
корзин используются SHA-256-отпечатки. Блокировка всегда временная: аккаунт в
базе не меняется и бессрочно не блокируется.

## Действующие лимиты

| Маршрут | Окно | На IP | На пару IP + идентификатор |
| --- | ---: | ---: | ---: |
| `POST /auth/login` и `POST /admin/auth/login` | 15 минут | 30 | 8 на email |
| `POST /auth/register` | 60 минут | 10 | 3 на email |
| `GET /auth/verify-email` | 15 минут | 30 | 10 на токен |
| `POST /auth/resend-verification` | 60 минут | 10 | 3 на email |
| `POST /auth/forgot-password` | 60 минут | 10 | 3 на email |
| `POST /auth/reset-password` | 15 минут | 20 | 5 на токен |

Пользовательский и административный вход используют одну область `login`,
поэтому переключение между двумя маршрутами не удваивает число попыток.
Успешный вход сбрасывает корзину пары IP + email, но не общий счётчик IP.
Один посторонний адрес не может временно заблокировать тот же email для входа
с другого адреса.

## Ответ при ограничении

Сервер отвечает HTTP `429`, добавляет заголовок `Retry-After` и возвращает:

```json
{
  "success": false,
  "message": "Слишком много запросов. Повторите попытку позже.",
  "status": "rate_limited",
  "retry_after_seconds": 420
}
```

## IP-адрес и reverse proxy

Приложение использует только адрес, вычисленный Express. Заголовок
`X-Forwarded-For` напрямую не читается.

- при локальном запуске и прямом доступе: `TRUST_PROXY_HOPS=0`;
- если перед API находится ровно один доверенный Nginx: `TRUST_PROXY_HOPS=1`;
- значение должно соответствовать реальному числу доверенных прокси.

Нельзя ставить `1`, если API одновременно доступен клиентам напрямую в обход
Nginx. На VPS порт Node API должен слушать внутренний интерфейс либо быть
закрыт межсетевым экраном.

## Настройки

```text
AUTH_RATE_LIMIT_ENABLED=true
AUTH_RATE_LIMIT_MAX_BUCKETS=50000
TRUST_PROXY_HOPS=0
```

Отключение допустимо только в изолированной локальной среде. Максимальное
число корзин ограничивает потребление памяти; просроченные записи очищаются
автоматически.

## Граница текущей реализации

Хранилище счётчиков работает в памяти одного процесса. Оно подходит для
текущего запуска GoStudy одним экземпляром API. Перезапуск процесса очищает
корзины. Перед запуском нескольких процессов или нескольких серверов нужно
подключить общее хранилище (например Redis) через выделенный интерфейс
`AuthRateLimitStore`.

Миграция PostgreSQL не требуется.
