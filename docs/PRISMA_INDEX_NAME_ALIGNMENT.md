# Согласование длинных имён индексов Prisma

Дата: 22 сентября 2026 года.

## Причина

PostgreSQL ограничивает имя объекта 63 байтами. В двух старых миграциях имена
индексов были длиннее этого ограничения, поэтому PostgreSQL автоматически
сократил их. Prisma вычисляет для этих же индексов другие 63-байтовые имена и
показывает ложное расхождение схемы.

Миграция `20260922190000_align_long_index_names` устраняет только это
расхождение. Таблицы, колонки и пользовательские данные она не изменяет.

## Поддерживаемые состояния

Для каждого индекса миграция отдельно проверяет текущую схему PostgreSQL:

- если найдено старое сокращённое имя, индекс переименовывается;
- если найдено новое имя Prisma, операция пропускается;
- если найдены оба имени или не найдено ни одного, миграция останавливается с
  понятной ошибкой, чтобы не скрыть повреждение или неожиданное состояние схемы.

Старые применённые миграции не редактируются. Благодаря этому их контрольные
суммы в таблице `_prisma_migrations` остаются неизменными.

## Применение

После распаковки патча в корень проекта остановите API и выполните:

```powershell
npm --prefix server run prisma:migrate:deploy
npm --prefix server run prisma:status
npm run server:lint
npm run server:test
npm --prefix server run test:modules
```

Итог `prisma:status` должен сообщить, что схема базы данных актуальна.
