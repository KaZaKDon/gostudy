# GoStudy — настройки уведомлений родителя

Дата: 11 сентября 2026 года.

## Назначение

Родитель управляет внутренними уведомлениями отдельно для каждого
подтверждённого привязанного несовершеннолетнего ребёнка. Настройки находятся
в кабинете: «Настройки» → «Уведомления».

## Категории

| Категория | События |
| --- | --- |
| Домашние задания | выдача, результат проверки и отмена задания |
| Дневник | публикация и обновление результата урока |
| Расписание | согласованный перенос и отмена занятия |
| Сообщения | сообщения преподавателя в чате ребёнка и в чате родителя |

Все категории по умолчанию включены. Настройка применяется только к новым
событиям: существующие уведомления не удаляются.

## Права и ограничения

- маршруты доступны только роли `PARENT`;
- ребёнок должен иметь активную подтверждённую связь с родителем;
- карточка ребёнка должна быть подтверждена, не архивирована, возраст — до
  18 лет;
- родитель не может сохранить настройки для чужого или недоступного ученика;
- выключение уведомления не меняет доступ к данным ребёнка и не отключает
  счётчики непрочитанных сообщений внутри раздела «Сообщения».

## Хранение

Таблица `parent_notification_preferences` содержит одну строку для уникальной
пары `parent_id` + `student_id`. Связь с `parent_students` каскадная: при
удалении самой связи её настройки также удаляются. Отсутствующая строка
трактуется как четыре значения `true`, поэтому действующие родители после
миграции продолжают получать уведомления без дополнительных действий.

## API

```text
GET  /api/v1/notifications/parent-settings
POST /api/v1/notifications/parent-settings
```

POST принимает идентификатор ребёнка и значения всех четырёх категорий. Это
исключает частично неопределённое состояние настроек.
