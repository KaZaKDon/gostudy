# GoStudy — Dashboard API админки на Node/NestJS

Дата: 3 сентября 2026 года.

## Назначение

Главная панель админки получает агрегированные показатели из PostgreSQL через
защищённый Node API. Старый PHP-маршрут `dashboard/stats.php` frontend больше
не вызывает.

## Маршрут

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/v1/admin/dashboard/stats` | администратор, модератор | сводные показатели платформы |

Передаётся отдельный административный токен в заголовке `X-Auth-Token`.

## Доступные показатели

Из текущей схемы PostgreSQL рассчитываются:

* общее количество аккаунтов;
* ученики;
* преподаватели;
* администраторы и модераторы;
* заблокированные и архивные аккаунты;
* преподаватели на проверке;
* ожидающие заявки ученик–преподаватель;
* запланированные и перенесённые уроки;
* активные домашние задания;
* отзывы и ответы на проверке;
* материалы и жалобы на материалы;
* личные сообщения и новые жалобы на сообщения.

Платежи и выплаты пока возвращают `0`. Эти счётчики будут подключены вместе с
платёжным модулем.

## Установка

Миграция базы данных не требуется. После замены файлов перезапустить API и
frontend:

```powershell
npm run server:dev
npm run dev
```
