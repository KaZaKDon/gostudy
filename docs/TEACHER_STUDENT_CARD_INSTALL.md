# Карточка ученика преподавателя

Дата: 24 июля 2026 года.

## Что исправлено

- Вкладки карточки ученика получают данные из API при первом открытии.
- Данные каждой вкладки кэшируются до закрытия раздела.
- Отзывы выводятся из опубликованных полей таблицы `reviews`.
- Для старых отзывов без `teacher_student_id` предусмотрен безопасный поиск
  по преподавателю, ученику и предмету.
- Занятия берутся из `lessons` и `lesson_results`.
- Домашние работы берутся из `homework` и последней попытки ученика.
- Материалы собираются из файлов класса и файлов заданий.
- Родительские контакты берутся из `student_profiles`.
- Для ещё не подключённых рабочей программы и оплат показывается понятное
  состояние вместо пустого экрана.
- Кнопки «Написать», «Домашнее задание» и «Журнал» открывают нужный раздел
  сразу для выбранного ученика.
- Добавлены завершение и возобновление обучения.

## API на хосте

Содержимое файлов документации копируется без Markdown-обёртки:

- `docs/api/teacher/student-details.php.md`
  → `/api/teacher/student-details.php`
- `docs/api/teacher/update-student-status.php.md`
  → `/api/teacher/update-student-status.php`

## База данных

Новая миграция не требуется. Используются таблицы, уже созданные модулями:

- уроки и журнал;
- домашние работы;
- класс;
- сообщения;
- уведомления;
- отзывы.

Перед установкой этого блока должна быть полностью выполнена безопасная
миграция `docs/database/migrations/2026-07-24_reviews.sql`.

## Проверка

1. Открыть кабинет преподавателя → «Мои ученики».
2. Выбрать ученика.
3. По очереди открыть все вкладки карточки.
4. Убедиться, что опубликованный отзыв виден во вкладке «Отзывы».
5. Проверить переходы «Написать», «Домашнее задание» и «Журнал».
6. Проверить завершение обучения только после отмены будущих уроков.
7. В архиве проверить «История обучения» и «Возобновить обучение».
