# Единая политика доступа родителя к аккаунту ребёнка

Дата актуализации: 23 сентября 2026 года.

## Назначение

`ParentChildAccessService` хранит единое серверное правило, по которому
родитель может действовать от имени несовершеннолетнего ребёнка. Переданный
клиентом `student_id` никогда не считается доказательством доступа.

Доступ существует только при одновременном выполнении условий:

- карточка принадлежит авторизованному родителю;
- карточка подтверждена, имеет `verified_at` и не архивирована;
- в карточке указан аккаунт ученика;
- связь `parent_students` активна и подтверждена;
- по точной дате рождения ребёнку ещё не исполнилось 18 лет.

После совершеннолетия, архивации карточки или отзыва подтверждённой связи
действия родителя блокируются автоматически без изменения старых записей.

## Подключённые действия

Общая политика применяется к следующим операциям:

- просмотр детского диалога и скачивание его вложений;
- создание и просмотр отзывов от имени ребёнка;
- просмотр состояния и отправка заявки выбранному преподавателю;
- создание заявки по программе «Доступное образование»;
- подтверждение ранее принятой заявки по программе «Доступное образование».

Единый сервис также формирует список доступных несовершеннолетних детей для:

- расписания родителя;
- дневника ребёнка;
- домашних заданий;
- семейной главной страницы;
- настроек родительских уведомлений;
- рассылки родителю уведомлений о событиях ребёнка.

Эти модули больше не содержат собственных копий правил возраста,
подтверждения и активности связи.

## Транзакции

Метод `hasCurrentMinorAccessIn` принимает активный Prisma-клиент транзакции.
Это позволяет проверять связь родителя и ребёнка в той же транзакции, в которой
создаётся заявка преподавателю, без отдельного запроса вне транзакции.

Метод `listCurrentMinorChildrenForPairsIn` выполняет ту же проверку для набора
пар «родитель — ребёнок» через активный Prisma-клиент. Он используется при
создании уведомлений родителям и не разрывает внешнюю транзакцию.

Миграция базы данных для политики не требуется.
