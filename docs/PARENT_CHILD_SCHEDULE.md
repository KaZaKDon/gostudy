# GoStudy — расписание детей в кабинете родителя

Дата: 9 сентября 2026 года.

## Назначение

Подтверждённый родитель видит недельное расписание каждого привязанного
несовершеннолетнего ребёнка. Раздел предназначен только для просмотра.

## Интерфейс

- в меню родителя добавлен пункт «Расписание детей»;
- если детей несколько, расписание переключается по имени ребёнка;
- показываются дата и время, преподаватель, предмет, тема, длительность и статус;
- имя выбранного ребёнка дополнительно указано возле каждого занятия;
- доступны предыдущая, текущая и следующая недели;
- кнопки входа в класс, переноса и отмены родителю не показываются.

## API и права

Используется `GET /api/v1/lessons/schedule` с необязательным параметром
`student_id`. Для роли `PARENT` сервер:

1. получает только активные и подтверждённые связи `parent_students`;
2. проверяет подтверждённую карточку ребёнка;
3. прекращает доступ после достижения ребёнком 18 лет;
4. отклоняет попытку запросить расписание чужого ученика;
5. возвращает изменения урока без права принять, отозвать или изменить их.

Новая миграция базы данных не требуется.
