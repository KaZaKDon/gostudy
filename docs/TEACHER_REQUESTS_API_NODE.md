# GoStudy — поиск преподавателя и заявки

**Дата:** 1 сентября 2026 года  
**Статус:** рабочая цепочка подключена к Node API

## Реализовано

- поиск опубликованных и подтверждённых преподавателей;
- просмотр публичной анкеты, предметов, цен и образования;
- отправка учеником заявки по выбранному предмету;
- защита от повторной активной связи и дублирования ожидающей заявки;
- список активных учеников, архива и новых заявок у преподавателя;
- принятие и отклонение заявки;
- создание или восстановление связи
  `преподаватель–ученик–предмет` при принятии;
- завершение и возобновление обучения;
- основные вкладки карточки ученика: обзор, занятия, родители;
- раздел «Мои преподаватели» у ученика;
- изменение видимости анкеты через Node API.
- уведомление преподавателя о новой заявке и ученика о результате;
- число ожидающих заявок рядом с разделом «Мои ученики».

## Маршруты

```text
GET  /api/v1/teachers
GET  /api/v1/teachers/details?teacher_id=ID
POST /api/v1/teachers/requests
GET  /api/v1/teacher/students
POST /api/v1/teacher/student-requests/respond
POST /api/v1/teacher/students/status
GET  /api/v1/teacher/student-details
GET  /api/v1/student/teachers
POST /api/v1/profile/teacher/visibility
```

## Проверка локально

До появления Node-админки подтверждение преподавателя для локального теста
выполняется в pgAdmin. В запросе заменить email на адрес тестового
преподавателя:

```sql
UPDATE teacher_profiles
SET verification_status = 'VERIFIED',
    is_visible = true,
    updated_at = CURRENT_TIMESTAMP
WHERE user_id = (
    SELECT id
    FROM users
    WHERE email = 'teacher@example.com'
      AND role = 'TEACHER'
);
```

Это только локальный способ проверки разработки. На рабочем сервере статус
выдаёт модератор через будущую админку.

Затем:

1. войти учеником и открыть «Найти преподавателя»;
2. выбрать предмет и отправить заявку;
3. войти преподавателем, открыть «Мои ученики» → «Заявки»;
4. принять заявку;
5. открыть расписание и назначить урок.

После применения миграции уведомлений новая заявка отображается на
колокольчике и увеличивает счётчик раздела. Уже обработанные до обновления
заявки задним числом в ленту не добавляются.
