# GoStudy — рабочие настройки аккаунта

> Интерфейс настроек постепенно переводится на NestJS/PostgreSQL. Описанные
> ниже PHP-маршруты остаются только для ещё не перенесённых разделов.

## Что исправлено

- удалены демонстрационные имена, контакты, документы и выплаты;
- настройки преподавателя показывают данные из Node-маршрута
  `GET /api/v1/profile/me`;
- профиль и документы открываются в общей анкете преподавателя;
- раздел документов сразу открывает шаг «Документы»;
- телефон сохраняется в `users.phone`;
- пароль меняется через Node-маршрут `POST /api/v1/auth/security` только после
  проверки текущего пароля;
- после смены пароля завершаются остальные сеансы;
- остальные сеансы можно завершить отдельной кнопкой через тот же Node-маршрут;
- преподаватель может скрыть подтверждённую анкету из поиска и вернуть её;
- настройки уведомлений отражают реально работающую логику платформы;
- платёжный блок не запрашивает реквизиты до утверждения юридической модели.

Новая миграция базы данных не требуется.

## Ещё не перенесённые API на хосте

Создать файлы и скопировать в них содержимое соответствующих `.md`:

```text
docs/api/profile/update-account.php.md
    → /api/profile/update-account.php

docs/api/profile/update-visibility.php.md
    → /api/profile/update-visibility.php
```

Безопасность аккаунта уже не использует `auth/security.php`: Node API
доступен по `GET/POST /api/v1/auth/security`. Описание контракта находится в
`docs/AUTH_SECURITY_API_NODE.md`.

## Локальный фронтенд

Скопировать папку `src` из архива в корень локального проекта с объединением
папок.

Основные изменённые пути:

```text
src/api/api.js
src/components/PasswordField/PasswordField.jsx
src/features/teacher-profile/TeacherProfileWizard.jsx
src/pages/ProfileStart/ProfileStart.jsx
src/pages/ProfileStart/StudentProfileForm.jsx
src/pages/Account/Account.jsx
src/pages/Account/components/AccountPanel.jsx
src/pages/Account/sections/Settings/
```

## Проверка

1. Открыть кабинет преподавателя → «Настройки».
2. Проверить реальные поля во вкладке «Профиль».
3. Нажать «Редактировать анкету», сохранить и убедиться, что произошёл возврат
   в настройки.
4. Во вкладке «Документы» нажать «Управлять документами» — должен сразу
   открыться шаг «Документы».
5. Изменить телефон и обновить страницу.
6. В «Безопасности» проверить неправильный текущий пароль, затем правильную
   смену пароля.
7. Если аккаунт открыт в другом браузере, нажать «Завершить остальные» и
   проверить, что второй сеанс перестал работать.
8. Для подтверждённого преподавателя выключить показ анкеты и убедиться, что
   она пропала из поиска ученика. Затем включить обратно.
