# GoStudy — семейная главная страница родителя

Дата: 11 сентября 2026 года.

## Назначение

Главная страница собирает наиболее важные события всех детей родителя, чтобы
не переключать ребёнка и раздел для обычной ежедневной проверки.

## Маршрут

```text
GET /api/v1/parent/dashboard
```

Маршрут доступен только роли `PARENT`. Параметры запроса не принимаются.

## Состав ответа

- список доступных детей;
- общее количество ближайших занятий;
- общее количество активных домашних заданий;
- до шести ближайших занятий;
- до шести активных домашних заданий;
- до шести последних опубликованных записей дневника.

Каждая запись содержит `student_id` и отображаемое имя ребёнка. Уроки и
дневник содержат `lesson_id`, задания — собственный `id`, поэтому frontend
открывает конкретную запись через уже существующие защищённые маршруты.

## Правила доступа

Ребёнок попадает в сводку только при одновременном выполнении условий:

- связь `parent_students` активна и подтверждена;
- карточка ребёнка подтверждена и не архивирована;
- ребёнку ещё не исполнилось 18 лет.

В записях дневника используются только опубликованные результаты завершённых
уроков. Поле `teacher_note` не выбирается из базы и не передаётся родителю.
Отменённые занятия и завершённые либо отменённые задания в текущую сводку не
попадают.

## Интерфейс

«Главная» является первым пунктом меню родителя и открывается по умолчанию.
Строки сводки ведут в существующие разделы с выбранным ребёнком и целевой
записью. Кнопки в заголовках открывают полное расписание, список заданий или
дневник.

## База

Модуль только читает существующие таблицы. Новая Prisma-модель и миграция не
требуются.
