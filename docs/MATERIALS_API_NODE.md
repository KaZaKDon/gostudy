# GoStudy — материалы на NestJS/PostgreSQL

Дата актуализации: 3 сентября 2026 года.

## 1. Что реализовано

Раздел «Материалы» работает через Node API и PostgreSQL. Преподаватель может
создать материал из одного или нескольких файлов, внешней ссылки,
интерактивного тренажёра либо их сочетания. Материал относится к предмету и
одному из разделов: учебники, тренажёры или дополнительные материалы.

Есть два независимых способа распространения:

- личная передача ученику по активной учебной связи — без предварительной
  модерации;
- публикация в общем каталоге — только после решения администратора или
  модератора.

Публичные бесплатные материалы открываются всем авторизованным ученикам и
преподавателям. Для платных материалов уже сохраняются цена в рублях и тип
доступа, но покупка отображается как «Скоро» до подключения платёжного модуля.

## 2. Основа будущих продаж

Доступ хранится отдельно от карточки материала в `material_access_grants`.
Назначение преподавателем создаёт право с источником `ASSIGNMENT`. Будущая
успешная покупка создаст такое же право с источником `PURCHASE`. Чтение и
скачивание уже проверяют действующее право доступа, поэтому платёжный модуль
добавит выдачу права, а не заменит устройство библиотеки.

Поддерживаемые источники: `ASSIGNMENT`, `PURCHASE` и `MANUAL` для будущей
ручной выдачи администрацией.

## 3. Модерация и ответственность

Статусы публикации: `PRIVATE`, `PENDING`, `APPROVED`, `REJECTED`, `HIDDEN`.
Новый публичный материал сразу получает `PENDING`. После изменения уже
проверенной публикации она снова возвращается в очередь. При отклонении
комментарий модератора обязателен.

Файлы и ссылки, переданные приватно в домашнем задании, классе или назначении,
не проходят предварительную модерацию. Для них сохраняются техническая
проверка файла, разграничение доступа, возможность жалобы, удаление доступа и
журнал административного решения.

Преподаватель отвечает за законность размещения и наличие прав на контент.
Платформа принимает обращения, скрывает спорную публикацию, при необходимости
отзывает уже выданные доступы и фиксирует решение.

## 4. Данные

Миграция: `server/prisma/migrations/20260903180000_materials/migration.sql`.

- `learning_materials` — карточка, автор, предмет, цена и статус;
- `material_items` — файлы и ссылки карточки;
- `material_assignments` — назначения по учебной связи;
- `material_access_grants` — права чтения сейчас и после будущей покупки;
- `material_reports` — жалобы и результаты рассмотрения.

Файлы сохраняются в закрытом `UPLOAD_PRIVATE_DIR/materials/<material_id>` и
не отдаются как статические URL.

## 5. API кабинета

Все маршруты требуют действующий пользовательский сеанс.

```text
GET   /api/v1/materials?view=mine|catalog|assigned
GET   /api/v1/materials/options
GET   /api/v1/materials/show?id=ID
POST  /api/v1/materials                         multipart/form-data
PATCH /api/v1/materials/:id
POST  /api/v1/materials/:id/submit-moderation
POST  /api/v1/materials/:id/hide
POST  /api/v1/materials/:id/assign
POST  /api/v1/materials/:id/unassign
POST  /api/v1/materials/:id/report
GET   /api/v1/materials/download?item_id=ID
```

`mine` доступен преподавателю, `assigned` — ученику, `catalog` — обеим ролям.
Назначить можно собственный материал либо бесплатную одобренную публикацию
другого автора. Предмет материала обязан совпадать с предметом активной связи.

## 6. API админки

Маршруты требуют роль `ADMIN` или `MODERATOR`:

```text
GET   /api/v1/admin/materials
PATCH /api/v1/admin/materials/:id/moderation
GET   /api/v1/admin/materials/reports
PATCH /api/v1/admin/materials/reports/:id
GET   /api/v1/admin/materials/download?item_id=ID
```

Решения записываются в `admin_audit_logs`; автор получает уведомление.

## 7. Ограничения загрузки

По умолчанию разрешено до 5 файлов, не более 20 МБ каждый и 50 МБ суммарно.
Проверяются расширение, MIME и сигнатура файла. Допустимы PDF, изображения,
TXT, DOC/DOCX, XLS/XLSX и PPT/PPTX. Unicode-имена нормализуются единым
механизмом загрузок.

```env
UPLOAD_PRIVATE_DIR=storage/private
UPLOAD_MATERIAL_MAX_BYTES=20971520
UPLOAD_MATERIAL_TOTAL_MAX_BYTES=52428800
```

## 8. Установка и проверка

```powershell
npm run server:prisma:generate
npm run server:prisma:migrate
npm run server:prisma:status
npm run server:dev
```

После этого перезапустить frontend и открыть `/admin/materials`.

Проверка: преподаватель создаёт личный материал и назначает его ученику;
ученик открывает его из уведомления и библиотеки. Затем преподаватель создаёт
публичный материал, администратор одобряет его, а ученик видит его в каталоге и
может отправить жалобу. Платный материал показывает цену и заглушку покупки.
