# GoStudy — регистрация родителя на Node.js

Дата: 20 сентября 2026 года.

## Граница этапа

На этом этапе создаётся только собственный аккаунт родителя. Данные ребёнка,
подтверждение полномочий законного представителя, связь родитель–ребёнок и
согласия на обработку данных ребёнка в эту операцию не входят.

Такое разделение не позволяет принять документы за ребёнка раньше, чем
платформа получила необходимые сведения и проверила основание представительства.

Прямая регистрация ученика разрешена только с 18 лет. Для роли `student`
обязательна дата рождения в формате `ГГГГ-ММ-ДД`; сервер проверяет календарную
дату и точную возрастную границу. Несовершеннолетний создаётся только из
кабинета родителя через действующий сценарий карточки ребёнка.

## Маршрут

`POST /api/v1/auth/register`

Для родителя используется тело запроса:

```json
{
  "role": "parent",
  "full_name": "Иванова Мария Сергеевна",
  "phone": "+7 900 000-00-00",
  "email": "parent@example.com",
  "password": "strong-password",
  "legal_acceptances": {
    "platform_documents": { "accepted": true },
    "personal_data": { "accepted": true },
    "marketing": { "accepted": false }
  }
}
```

## Проверки и сохранение

- роль должна иметь значение `parent`;
- ФИО обязательно, длина — от 3 до 255 символов;
- телефон обязателен, длина — от 7 до 40 допустимых символов;
- обязательный телефон родителя нельзя удалить через настройки, но можно заменить;
- email, пароль и юридические согласия проверяются общим модулем регистрации;
- создаётся пользователь с ролью `PARENT` и заполненными `full_name`, `phone`;
- профиль ученика или преподавателя не создаётся;
- кабинет родителя считается начально заполненным;
- подтверждение email выполняется действующим почтовым сценарием;
- согласия фиксируют только решения родителя о его собственных данных.

Новая миграция базы не требуется: роль `PARENT` и поля пользователя уже есть
в Prisma-схеме.

## Интерфейс

На странице регистрации доступна вкладка «Родитель». После подтверждения почты
родитель попадает в отдельный каркас кабинета:

- «Мои дети»;
- «Сообщения»;
- «Настройки» — контакты и безопасность.

Раздел «Мои дети» подключён к отдельному модулю карточек ребёнка, описанному в
`PARENT_CHILD_PROFILE_API_NODE.md`.

## Продолжение родительского сценария

Карточка ребёнка, точная дата рождения, заявление о статусе представителя,
отдельное согласие на обработку данных, проверка полномочий, создание или
привязка ученического аккаунта и проверенная связь `parent_students`
реализованы.
