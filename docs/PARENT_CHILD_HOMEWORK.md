# GoStudy — домашние задания детей в кабинете родителя

Дата: 9 сентября 2026 года.

## Назначение

Подтверждённый родитель видит домашние задания каждого привязанного
несовершеннолетнего ребёнка, результаты проверки и файлы. Все действия
родителя выполняются только в режиме просмотра.

## Интерфейс

- в меню родителя добавлен пункт «Домашние задания»;
- задания переключаются по имени ребёнка;
- сохранены фильтры «В работе», «На проверке», «Просроченные», «Проверенные»
  и «Отменённые»;
- карточка показывает описание, срок, преподавателя, предмет и статус;
- родитель видит ответы ребёнка, историю попыток, оценку и комментарий
  преподавателя;
- можно скачивать файлы задания и отправленные ребёнком файлы;
- формы отправки, доработки, проверки и отмены родителю не показываются.

## API и права

`GET /api/v1/homework` принимает необязательный `student_id`. Для родителя
сервер возвращает только выбранного ребёнка после проверки активной связи и
подтверждённой карточки. Те же проверки выполняются при открытии задания и при
скачивании каждого файла. Доступ прекращается после достижения ребёнком 18 лет.

Методы отправки, проверки и отмены сохранили прежние ограничения ролей и не
разрешают родителю изменять домашнюю работу.

Новая миграция базы данных не требуется.
