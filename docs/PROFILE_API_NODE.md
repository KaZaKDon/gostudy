# GoStudy — Node API сеансов и анкет

**Дата:** 31 августа 2026 года  
**Статус:** реализовано

## Причина переноса этого блока

Регистрация и вход уже выполнялись в NestJS и создавали сеанс в PostgreSQL,
но анкета обращалась к старым PHP-маршрутам. PHP не мог проверить Node-токен и
возвращал сообщение «Сессия недействительна».

Теперь получение пользователя, справочники и основное сохранение анкет
используют один источник — PostgreSQL и NestJS.

## Авторизация

Защищённые маршруты принимают один из заголовков:

```http
X-Auth-Token: <непрозрачный токен>
```

или:

```http
Authorization: Bearer <непрозрачный токен>
```

В `auth_sessions` хранится только SHA-256 токена. Проверяются срок действия
сеанса, статус пользователя и подтверждение email. При успешном запросе
обновляется `last_used_at`.

## Маршруты

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/v1/profile/me` | текущий пользователь и его профиль |
| GET | `/api/v1/profile/teacher-options` | предметы, направления и возрастные группы |
| POST | `/api/v1/profile/teacher` | сохранить основную анкету преподавателя |
| GET | `/api/v1/profile/student` | получить анкету ученика |
| POST | `/api/v1/profile/student` | сохранить анкету ученика |

## Транзакции

Анкета преподавателя сохраняет одной транзакцией:

- основную информацию и цены;
- предметы;
- направления подготовки по предметам;
- возрастные группы;
- образование;
- настройки программы «Доступное образование»;
- имя, аватар и признак завершённого профиля пользователя.

Анкета ученика одной транзакцией сохраняет профиль, контактные данные и
признак завершения. Для ученика младше 18 лет обязательны имя родителя и хотя
бы один его контакт: телефон или email.

## Граница текущего этапа

В Node перенесена основная анкета. Загрузка фото, документов и видеовизитки,
модерация документов и управление видимостью преподавателя остаются отдельным
следующим этапом. Старые `.php.md` в `docs/api/profile` сохраняются как
спецификация этих ещё не перенесённых функций.

## Обновление существующей локальной базы

Миграция `20260831110000_profile_sessions` только добавляет поля, таблицы и
начальные справочники. Она не удаляет пользователя, согласия, email или
действующие сеансы.

```powershell
npm run server:prisma:generate
npm run server:prisma:migrate
npm run server:prisma:status
```

После миграции перезапустить `npm run server:dev` и `npm run dev`.

## Переходный режим кабинета

До переноса расписания, домашних заданий, сообщений и уведомлений эти разделы
не отправляют Node-токен в старый PHP API. Фоновые опросы отключены флагами
`API_FEATURES`, поэтому кабинет не создаёт постоянные ответы `401` и не
показывает ложное сообщение о недействительной сессии. Каждый флаг включается
после реализации соответствующего NestJS-модуля.
