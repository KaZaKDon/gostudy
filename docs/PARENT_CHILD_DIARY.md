# GoStudy — дневник обучения детей в кабинете родителя

Дата: 9 сентября 2026 года.

## Назначение

Подтверждённый родитель видит опубликованные результаты занятий каждого
привязанного несовершеннолетнего ребёнка. Дневник работает только в режиме
просмотра.

## Интерфейс

- в меню родителя добавлен пункт «Дневник детей»;
- записи переключаются по имени ребёнка;
- доступны общая статистика, предметы и история проведённых занятий;
- показываются дата, преподаватель, тема, посещаемость, оценка, результат и
  опубликованный комментарий преподавателя;
- из карточки занятия можно открыть связанное домашнее задание;
- личная заметка преподавателя не передаётся родителю;
- изменение результатов и другие действия родителю недоступны.

## API и права

Для родителя используется отдельный маршрут
`GET /api/v1/parent/children/diary`. Параметр `student_id` выбирает ребёнка;
остальные фильтры и пагинация совпадают с ученическим дневником.

Перед выдачей данных сервер проверяет активную связь `parent_students`,
подтверждённую карточку ребёнка, принадлежность карточки текущему родителю и
возраст ребёнка. Запрос дневника чужого ученика отклоняется. После достижения
ребёнком 18 лет доступ прекращается.

Возвращаются только завершённые уроки с опубликованным результатом. Поле
`teacher_note` исключается сервером и не зависит от интерфейса.

Новая миграция базы данных не требуется.
