# GoStudy — ученики в админке на Node/NestJS

Дата: 3 сентября 2026 года.

## Назначение

Раздел даёт администратору и модератору достоверный список учеников и полную
карточку каждого ученика. Старые PHP-маршруты `/api/admin/students/*.php`
frontend больше не использует.

## Маршруты

Все маршруты требуют действующий административный токен в `X-Auth-Token`.

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/v1/admin/students` | администратор, модератор | список, поиск, фильтр статуса и пагинация |
| `GET` | `/api/v1/admin/students/:id` | администратор, модератор | полная карточка ученика |

Блокировка, архивирование и восстановление выполняются общим маршрутом
`PATCH /api/v1/admin/accounts/:id/status`. Изменять статус аккаунта может
только администратор. Модератору доступен просмотр без этих кнопок.

## Список и поиск

Список содержит аккаунт, основные сведения анкеты, число активных
преподавателей, заявок и уроков. Поиск проверяет:

* ID, ФИО, email и телефон ученика;
* имя, телефон и email родителя;
* город, предметы и цель обучения.

Поддерживаются статусы `active`, `blocked`, `archived` и `deleted`.
Новые операции архивирования используют статус `archived`; `deleted`
сохраняется в фильтре только для совместимости со старыми данными.

## Карточка ученика

Карточка показывает:

* статус аккаунта, подтверждение email и заполненность анкеты;
* все поля учебной анкеты и контакты;
* имя, телефон и email родителя или представителя;
* активные и архивные связи с преподавателями;
* последние заявки преподавателям;
* последние уроки и общее количество уроков;
* последние домашние задания, состояние попытки, оценку и общий счётчик.

Фотография профиля будет подключена общим модулем медиахранилища после
переноса на российский VPS.

## Текущие ограничения

Модель сообщений ещё не перенесена в Prisma, поэтому API возвращает для неё
нулевой счётчик, не обращаясь к PHP. Домашние задания уже читаются из
действующего Node-модуля.

Отдельная связь с аккаунтом родителя также ещё не реализована. До её появления
карточка отображает родительские контакты, сохранённые в анкете ученика.

## Установка

Сам раздел учеников не требует отдельной миграции. Для домашних заданий должна
быть применена миграция `20260903140000_homework`, затем нужно перезапустить
Node API и frontend:

```powershell
npm run server:prisma:migrate
npm run server:dev
npm run dev
```
