# v0.7

Дата: 17.07.2026

## Анкета преподавателя: шаг «Преподавание»

### Реализовано

* предметы загружаются из `subject_groups` и `subjects`;
* направления подготовки ограничиваются связями `subject_preparations`;
* возраст учеников загружается из `student_age_groups`;
* выбор преподавателя сохраняется в `teacher_subjects`,
  `teacher_subject_preparations` и `teacher_age_groups`;
* добавлен API `profile/teacher-options.php`;
* добавлен транзакционный API `profile/update-teacher.php`;
* чтение анкеты через `profile/me.php` переведено на нормализованные связи;
* образование сохраняется в `teacher_education` с сохранением существующих ID;
* фото профиля загружается с сайта и сохраняется в публичном медиахранилище;
* видеовизитка загружается с сайта в формате MP4 или WebM;
* дипломы и сертификаты загружаются в закрытое хранилище;
* добавлены серверная проверка MIME, размеров и безопасная генерация имён;
* добавлены удаление файлов и защищённая выдача документов модератору;
* подготовлена миграция внешних ключей и удаления устаревших полей;
* обновлены API поиска и административной карточки преподавателя.

### Архитектурные решения

* `teacher_id` во всех таблицах анкеты равен `users.id`;
* текстовые списки предметов, целей и возрастов больше не используются;
* документы преподавателя сохраняются отдельным multipart API и не входят
  в JSON-запрос сохранения анкеты;
* закрытые документы не имеют публичных URL;
* повторная отправка анкеты переводит её в статус `pending`.

### Архитектурные решения

Принято

* Users является техническим реестром аккаунтов.

* Используется архивирование.
* UI Library отделена от Business Components.
* Каждый новый раздел начинается только после завершения предыдущего.
