# GoStudy — контактный телефон аккаунта на NestJS/PostgreSQL

**Дата:** 8 сентября 2026 года  
**Статус:** реализовано и проверено

## Назначение

Сохранение контактного телефона перенесено из
`api/profile/update-account.php` в существующий модуль `profile`. Отдельный
сервис и таблица не создаются: телефон относится к аккаунту и хранится в
`users.phone`.

## Маршрут

| Метод | Маршрут | Доступ |
| --- | --- | --- |
| `POST` | `/api/v1/profile/account` | авторизованный пользователь |

Тело запроса:

```json
{
  "phone": "+7 (900) 000-00-00"
}
```

Телефон очищается от пробелов по краям. Пустая строка удаляет номер. Допустимы
цифры, пробелы и символы `+ ( ) . -`; непустой номер содержит от 7 до 40
символов.

Ограничение 40 символов соответствует типу `users.phone VARCHAR(40)` в
PostgreSQL. Поэтому миграция базы данных не требуется.

## Ответ

API возвращает сообщение `Контактные данные сохранены` и обновлённое публичное
представление пользователя. Форма React подключена к Node API и больше не
обращается к `profile/update-account.php`.
